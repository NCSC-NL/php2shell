# Official PHP2Shell product findings on 23 October 2026

This review covers CVE-2026-109618 and CVE-2026-109619 for the 611 inventory entries that were `Investigation` or `Vulnerable` for at least one CVE at main commit `2fdc314`. Entries already marked `Fix`, `Not vuln` or `Workaround` for both CVEs were excluded. Findings below come from public vendor or upstream communications visited during this review; prior chat information was not used.

The status names follow [software/README.md](../../README.md). Each finding applies only to the stated version and deployment. A product can appear under both `Vulnerable` and `Fix` for different builds. A PHP runtime update is not an application release. Future patch dates, builds in QA and configuration mitigations are not `Fix`.

For Alpine and Fedora, the fix determination combines the official distribution package version with PHP’s explicit fixed-release advisory. No conclusion is inferred for unrelated branches, architectures, extensions or customer deployments.

## Investigation and review limits

The [coverage ledger](review-coverage.json) lists every eligible product, its starting status for each CVE, source visits and whether a finding above was verified. Entries without an official product-specific determination are not included in the confirmed tables. The existing inventory status is preserved for those entries; absence of a bulletin does not disprove an existing assessment. The ledger’s review result is not a replacement VEX status.

Cisco’s remaining named investigations and Fortinet’s FortiDDoS, FortiDDoS-F, FortiClient Cloud Services, FortiSOAR and FortiSOAR PaaS remain unresolved in the reviewed advisories. Cisco Panoptica is absent from the latest named lists; omission is not treated as explicit confirmation. Broadcom CloudSOC CASB and Content Analysis remain under investigation.

WordPress.com says every hosted site is protected, including plugin-enabled plans, but the reviewed notices do not identify a fixed build or explicitly describe the protection mechanism. This review records that assurance without inferring a released PHP fix or changing the entry to `Not vuln`. The service assurance does not cover self-hosted WordPress. Sources: [WordPress.com support](https://wordpress.com/support/php-security-update-october-2026-cve-2026-109618-and-cve-2026-109619-php2shell/) and [Automattic](https://automattic.com/2026/10/21/php2shell/).

Public pages that returned access errors, bot checks, login pages or empty JavaScript shells did not supply a determination. Browser-rendered public advisories were used for F5, HPE, NetApp, Check Point and Quest. Community issue comments were used only where a repository owner or member supplied the decisive confirmation; arbitrary user reports were not elevated to vendor assessments. Part-DB architecture reports and the Roundcube regression qualify the respective image findings.

The findings are a dated snapshot of the public evidence verified here, not an assurance that no other vendor has published information. Search indexing and inaccessible pages limit discovery. No scanning, exploitation or private support information was used.
